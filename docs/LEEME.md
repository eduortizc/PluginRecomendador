# Inicio de Recomendador_ext

Este proyecto comienza como un recomendador independiente. El usuario trabaja en Mac y creó la carpeta `Recomendador_ext`, con los Markdown dentro de `docs`. La conexión con Moodle se realizará en una etapa posterior.

La actualización del 29 de septiembre de 2026 sustituye el arranque anterior centrado en instalar un bloque de Moodle. El primer encargo ahora es construir un pequeño prototipo local con datos simulados.

## Colocación de los archivos

| Ruta desde Recomendador_ext | Contenido |
| --- | --- |
| `AGENTS.md` | Instrucciones para todo el proyecto. |
| `docs/LEEME.md` | Esta guía y el mensaje de inicio. |
| `docs/01_CONTEXTO_TESIS.md` | Problema y objetivos de la tesis. |
| `docs/02_ALCANCE_Y_PLAN.md` | Requisitos y desarrollo por etapas. |
| `docs/03_ENTORNO_Y_ARQUITECTURA.md` | Organización del prototipo y futura integración. |
| `docs/04_PRIMERA_ETAPA.md` | Primera tarea y sus criterios de aceptación. |
| `docs/05_SEGUIMIENTO.md` | Estado, decisiones y bitácora. |

Coloca el contenido del ZIP actualizado en tu carpeta existente siguiendo estas rutas. Si todavía tienes el antiguo `AGENTS.md` dentro de `docs`, muévelo a la raíz y usa la versión actualizada. No deben quedar instrucciones antiguas en `docs/AGENTS.md` que contradigan el nuevo alcance.

Este paquete actualiza los documentos; no modifica por sí mismo tu carpeta en el Mac.
